# Approved updater and About design

Setup offers an unchecked automatic-update-check option, also editable in About. Opt-in checks run at most daily while app is opened; no background service, no silent downloads or installs. Manual checking always available. Release metadata comes only from jlfernandes22/gemini-pocket on GitHub. Download starts only after confirmation. Show rounded themed sheet with circular wavy progress and real percentage; Cancel aborts transfer. Verify size, SHA-256 asset digest, package identity, newer Android versionCode and current signing certificate before Android installer. Unknown-source permission is user-controlled; return resumes pending installation once. Never send tokens to GitHub download hosts. Downloads live in private files/updates, outside attachment cleanup. No downgrade to public builds from higher development builds.

About links: project, releases, issues, privacy, MIT license, geminiAssist inspiration. Native themed sheet, installed version and update opt-in. Existing session and upload code remain unchanged. No VScreen. Test URL/version rules, manifest/provider boundary, compile/sign/install. Actual updater replacement requires a newer release signed by the same key and user installer confirmation; do not claim that path tested by installing via shell.
